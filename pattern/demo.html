A storefront your agent operates — with receipts

The PaperTrail pattern on a deliberately non-research domain: the identical ~130-line library, pointed at a shop. Four tools register on document.modelContext (or a local stand-in), every call lands in the ledger, every cart line carries a receipt linking it to the tool call that added it, and checkout is a write an agent must be trusted to run — so its receipts are refused for re-execution and can only be audited.
