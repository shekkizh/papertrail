A journal hosts a shared review — and delegates its audit tools to your agent

This host page embeds a PaperTrail snapshot in an <iframe allow="tools">. The snapshot registers its six read tools with exposedTo: [this origin] (via ?embedOrigin=), so the host can discover them with document.modelContext.getTools({ fromOrigins: [...] }) — the WebMCP spec's cross-origin delegation surface. Execution stays with the embedding agent (Chrome with the WebMCP flag), not this page: cross-top-level execution is intentionally out of scope.
